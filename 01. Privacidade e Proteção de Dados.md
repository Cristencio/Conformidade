# 1. Privacidade e Proteção de Dados

## Objectivo
Estabelecer regras para recolha, utilização, conservação, partilha e eliminação de dados pessoais.

## Requisitos
1. Recolher apenas os dados necessários para finalidades identificadas.
2. Informar o utilizador sobre os dados recolhidos e a finalidade do tratamento.
3. Identificar a entidade responsável pelo tratamento e os contactos relevantes.
4. Obter consentimento quando a base legal aplicável o exigir.
5. Não tratar consentimento como autorização genérica para qualquer finalidade.
6. Permitir retirar consentimentos quando aplicável.
7. Separar dados obrigatórios de dados opcionais.
8. Definir prazos de conservação por categoria de dados.
9. Eliminar ou anonimizar dados quando deixarem de ser necessários, respeitando obrigações legais.
10. Permitir exercer direitos de acesso, rectificação, apagamento, oposição e portabilidade quando aplicáveis.
11. Restringir o acesso a dados pessoais segundo o princípio do menor privilégio.
12. Registar acessos administrativos relevantes.
13. Proteger dados em trânsito e em repouso.
14. Não expor dados pessoais em URLs, logs ou mensagens de erro.
15. Definir regras para partilha com fornecedores e subcontratantes.
16. Formalizar responsabilidades e obrigações dos fornecedores que tratam dados.
17. Avaliar transferências internacionais de dados.
18. Aplicar minimização de dados em relatórios e ambientes de teste.
19. Não utilizar dados reais em testes sem justificação e protecção adequadas.
20. Definir procedimento para incidentes e violações de dados.
21. Avaliar impacto de privacidade em tratamentos de maior risco.
22. Evitar recolha de dados sensíveis sem necessidade e fundamento legal.
23. Proteger dados de menores com salvaguardas adequadas.
24. Disponibilizar política de privacidade clara, actualizada e acessível.
25. Rever periodicamente os fluxos de dados e as permissões.

## Evidências de conformidade
- Inventário de dados e finalidades.
- Política de privacidade e registos de consentimento.
- Matriz de acesso e prazos de conservação.
- Procedimento de incidentes e pedidos dos titulares.

## Critério de aceitação
Cada categoria de dados deve ter finalidade, fundamento, acesso autorizado, prazo de conservação e procedimento de eliminação documentados.
