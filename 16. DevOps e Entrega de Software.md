# 16. DevOps e Entrega de Software

## Requisitos
1. Manter código em controlo de versões.
2. Definir estratégia de branches e integração.
3. Automatizar build e testes.
4. Implementar pipeline CI.
5. Implementar pipeline CD com controlos adequados.
6. Não publicar alterações sem testes essenciais.
7. Armazenar artefactos de build de forma rastreável.
8. Gerir dependências com versões fixadas.
9. Fazer análise de vulnerabilidades de dependências.
10. Fazer análise estática de código quando adequada.
11. Guardar segredos fora do repositório.
12. Utilizar variáveis de ambiente ou gestor de segredos.
13. Separar configurações por ambiente.
14. Aplicar migrações de base de dados de forma controlada.
15. Ter plano de rollback.
16. Utilizar feature flags quando úteis.
17. Fazer deploy progressivo em sistemas críticos.
18. Monitorizar a aplicação após deploy.
19. Registar versão e autor da publicação.
20. Proteger permissões do pipeline.
21. Assinar ou verificar artefactos quando necessário.
22. Documentar processo de release.
23. Automatizar testes de regressão.
24. Evitar deploy manual sem rastreabilidade.
25. Rever e actualizar ferramentas de build e entrega.
