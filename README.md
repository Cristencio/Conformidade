## Como utilizar
1. Tratar cada ficheiro como documento independente.
2. Marcar requisitos como obrigatórios, condicionais ou não aplicáveis.
3. Registar evidências antes de considerar um requisito conforme.
4. Adaptar obrigações legais ao país, sector e modelo de negócio.
5. Manter histórico de alterações e responsáveis.
